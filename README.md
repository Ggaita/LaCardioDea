# Proyecto Mapa Cardioprotegido La Pampa

## Descripción

Este proyecto muestra un mapa interactivo de La Pampa con puntos de desfibriladores, geolocalización del usuario y rutas peatonales hasta los puntos. Incluye:

- Mapas base (OpenStreetMap)
- Carga de puntos desde WFS GeoJSON
- Marcador de ubicación actual con actualización periódica
- Rutas peatonales con `leaflet-routing-machine`
- Service Worker para cachear recursos y permitir uso offline
- Modularización de código en JavaScript moderno (ES6+)

---

## Tecnologías

- JavaScript (ES6 modules)
- [Leaflet](https://leafletjs.com/)
- [Leaflet Routing Machine](https://www.liedman.net/leaflet-routing-machine/)
- Service Workers
- Fetch API
- GeoServer WFS
